## 🛠️ Technologies Used

* **Frontend Framework:** React.js (Bootstrapped with Vite)
* **Routing:** React Router v6
* **Styling:** Pure Vanilla CSS (CSS3) with CSS Variables for theme management
* **Layouts:** Flexbox & CSS Grid
* **Icons & Assets:** Unicode Icons & High-Quality Stock Imagery from Unsplash

## 🚀 Key Improvements Made

* **Modern UI/UX Design:** Replaced the outdated, static interface with a premium, dynamic, and aesthetic design featuring glassmorphism elements, deep shadows, and an elegant color palette (`#0f4c81` Blue & `#f7a400` Gold).
* **Full Responsiveness:** Engineered mobile-first layouts ensuring flawless experiences across mobile, tablet, and desktop devices.
* **Performance Optimization:** Leveraged Vite for lightning-fast builds and HMR. Used optimized CSS and avoided heavy external CSS frameworks to keep the bundle size extremely small.
* **Interactive Animations:** Implemented subtle micro-interactions like hover states on buttons, smooth image scaling in the gallery, and floating badges to boost user engagement.
* **Component-Based Architecture:** Reorganized the entire codebase into reusable, maintainable React components (`Navbar`, `Hero`, `AboutSection`, `Gallery`, `Testimonials`, `Footer`) for clean folder structure.
* **Enhanced Navigation & Routing:** Implemented client-side routing using `react-router-dom` for seamless page transitions without full browser reloads.

3. Install dependencies:
